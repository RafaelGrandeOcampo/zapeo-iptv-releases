# Zapeo IPTV — descargas

Reproductor de TV por Internet para listas M3U, cuentas Xtream Codes y portales Stalker. La aplicación no incluye canales: cargas la lista que te da tu proveedor.

Las versiones están en **[Releases](https://github.com/RafaelGrandeOcampo/zapeo-iptv-releases/releases/latest)**. Zapeo avisa al arrancar cuando hay una nueva.

| Plataforma | Archivo | Instalación |
|---|---|---|
| Android / Android TV / Fire TV | `app-arm64-v8a-release.apk` (la mayoría), `app-armeabi-v7a-release.apk` (dispositivos antiguos) | Abre el APK y permite instalar apps de origen desconocido. Cada versión se instala encima de la anterior |
| Windows | `zapeo-iptv-windows-x64.zip` | Descomprime y abre `iptv_player.exe` |
| Linux | `zapeo-iptv-linux-x64.tar.gz` | Necesita libmpv (`sudo apt install libmpv2`). Descomprime y ejecuta `./instalar.sh` dentro de la carpeta `bundle` |
| macOS | `zapeo-iptv-macos.zip` | Sin firmar: la primera vez, clic derecho → Abrir |
| iOS | `zapeo-iptv-ios-unsigned.ipa` | Sin firmar: instálalo con AltStore o Sideloadly |

Al actualizar, tus listas, favoritos y ajustes se conservan.
